# Docker Containers

Prebuilt, importable Docker containers.

## RePythonNET-MCP

A self-contained image of
[SEKOIA-IO/RePythonNET-MCP](https://github.com/SEKOIA-IO/RePythonNET-MCP)
is published as a downloadable release bundle.

[Download the latest RePythonNET-MCP bundle](https://github.com/kvmc/docker-containers/releases/tag/repythonnet-mcp-latest)

After downloading:

```bash
tar -xzf repythonnet-mcp-bundle-amd64.tar.gz
./run.sh
```

Only Docker is required on the destination host. No local build, source checkout,
Python installation, or Mono installation is needed.
